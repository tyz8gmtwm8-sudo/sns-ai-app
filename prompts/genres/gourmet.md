## グルメ
- 企画：実際に行った（行く）お店を主役にする。「〇〇エリアの〇〇」「〇〇選」「食べ比べ」「断面・湯気・肉汁などシズル感」が伸びやすい。
- キャプション：店名・最寄り駅やエリア・メニュー名・価格・営業時間・定休日・予約の要否など、保存したくなる実用情報を入れる。ネタ帳に無い情報は書かずに【要確認】とする。下の「キャプションの型」に必ず従う。
- 動画：最初の1秒で料理のいちばんおいしそうな瞬間（断面、チーズが伸びる、湯気）を見せる。外観・内観・メニュー表も撮る。
- ハッシュタグ：地域名×ジャンル（例：#梅田ランチ #神戸カフェ）を必ず入れる。

### キャプションの型（この形・改行・記号のまま作る）
```
🏷️ {店名} ︴{都道府県}/{エリア}

 menu 
✧ {メニュー名} ¥{価格}
✧ {メニュー名}（{分かりにくい料理名なら短い説明}） ¥{価格}


{エリア}にある{どんなお店か}{記号}
{お店の魅力やおすすめポイント}{記号}

中でも絶対頼みたいのが
{いちばんのおすすめメニュー} {絵文字}
{見た目や味の感想}{記号}

{ほかのメニューの紹介}
{その感想}{記号}

{行く前に知っておきたいこと（数量限定・混雑・予約など）}
{だからどうするのがおすすめか}{記号}

気になる方は保存して行ってみてね🍴︎

──────────────────
インスタ　@{お店のInstagramアカウント}
住所　{住所}
交通　{最寄り駅と出口}から徒歩{〇}分
営業時間　{営業時間} ※{定休日}
──────────────────
```
- { } の部分は、ネタ帳の内容に置き換える。{ } の中の説明の言葉（「いちばんのおすすめメニュー」など）は、本文に書かない。
- 本文の1行は20文字前後までにする。長くなるときは、意味の切れ目で改行して2行に分ける。1段落は2〜3行にし、段落の間に空行を入れる。
- {記号} の部分には ୨୧ ♪ ⟡.· ⸝⋆ ◎ 🐾 のような、やわらかい記号や絵文字を1つ置く（言葉の途中には入れない）。
- menu の行はネタ帳にあるメニューと価格だけを書く。日本ではなじみの薄い料理名には、かっこで短い説明を付ける。価格が分からないものは「¥【要確認】」とする。
- 区切り線の中は「インスタ」「住所」「交通」「営業時間」の見出しを付け、見出しのあとに全角スペース（　）を1つ入れる。「・」は付けない。ネタ帳に無い情報は【要確認】と書く。
- ハッシュタグはキャプションに書かない（別の欄で作る）。
